! VeloX built-in minimal content-blocking list.
!
! This is NOT a copy of EasyList/EasyPrivacy (https://easylist.to) and is not
! fetched from the network (VeloX ships no list-update mechanism yet, see
! docs/decisions.md D8). It is a small, hand-picked subset of publicly known
! ad-serving/tracking infrastructure domains, written in the `||domain^`
! syntax those community lists use so a real EasyList-format file can be
! merged in later (see `Config::extra_blocklist_path`) without changing the
! parser.
!
! Format understood by VeloX's parser (see `blocklist.rs`):
!   ||domain^        block `domain` and any subdomain of it
!   @@||domain^      exception: never block `domain` (or its subdomains)
!   ! comment        ignored
!   anything with ## or #@# (element hiding)  ignored
!   anything else that isn't a ||domain^ rule  ignored
