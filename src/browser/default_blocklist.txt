! VeloX built-in minimal content-blocking list.
!
! This is NOT a copy of EasyList/EasyPrivacy (https://easylist.to) and is not
! fetched from the network (VeloX ships no list-update mechanism yet, see
! docs/decisions.md D8). It is a small, hand-picked subset of publicly known
! ad-serving/tracking infrastructure domains, written in the `||domain^`
! syntax those community lists use so a real EasyList-format file can be
! merged in later (see `Config::extra_blocklist_path`) without changing the
! parser.
!
! This file only uses the `||domain^` form, but VeloX's parser (see
! `blocklist.rs`, extended for Issue #23) understands considerably more of
! the real EasyList/EasyPrivacy syntax now: generic `*`/`^`/`|`-anchored
! patterns (not just domain anchors), `$` options (resource type,
! `domain=` scoping), and `@@` exceptions on either rule form. See
! `blocklist.rs`'s module doc comment for the exact supported subset and
! what's intentionally not implemented (regex filters, cosmetic/element
! hiding, content-modifying options).
